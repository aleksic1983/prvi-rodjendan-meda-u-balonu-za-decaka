# Interactive First Birthday Invitation

A mobile-first interactive first birthday invitation featuring a soft balloon and teddy bear theme. Built with HTML, CSS and JavaScript, with animated scenes, personalised event details and background audio.

## Live Demo

[View the interactive invitation](curious-sprinkles-e7af5e.netlify.app)

> The invitation text is in Serbian, but all content, colours, images and event details can be customised for other languages and clients.

## Features

- Mobile-first responsive design
- Animated scene transitions
- Balloon-themed animations
- Personalised birthday details
- Custom photo section
- Background music and sound effects
- Automatic music stop on the final scene
- Customisable colour variables
- Optimised for smartphones

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Customisation

The invitation can be customised with:

- Child’s name and age
- Date and time
- Venue
- Personal message
- Images
- Colours
- Music
- Language
